ШКОЛЬНАЯ БАРАХОЛКА — версия с безопасным контактом

В форме создания объявления добавлено поле «Номер телефона для связи».
Номер телефона не показывается в карточке объявления и открывается только после оформления заказа.

Важно:
- Эта версия работает как статический прототип и хранит данные только в браузере.
- Для того чтобы все школьники видели одни и те же объявления, нужна общая база данных и сервер.
- Реальные платежи через сайт здесь не выполняются.
- Не добавляйте номера банковских карт, CVV, пароли или SMS-коды.
