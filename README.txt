

# 🏫 School Barter

Сайт-барахолка для учеников школы №52.

## Возможности

- 👤 Профиль пользователя
- 📦 Размещение объявлений
- 💰 Фиксированная цена, диапазон цены или бесплатно
- 🏫 Указание класса, корпуса и этажа
- 📱 Контакт продавца
- 💳 Информация об оплате
- 🔄 Автоматическая загрузка объявлений
- ☁️ Supabase как общий сервер базы данных

## Технологии

- HTML
- CSS
- JavaScript
- Supabase
- GitHub Pages

## Запуск

Сайт размещён на GitHub Pages.

Supabase используется для хранения профилей и объявлений.

## Безопасность

В браузере используется только публичный Supabase Publishable Key.

Секретные ключи и `service_role` ключи нельзя добавлять в код сайта.
